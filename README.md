# Practical No. 9: File Handling in Python

🎯 Aim
To write a python program to perform file manipulations—including opening, closing, reading, writing, appending, and copying content from one file to another.

📌 Objective
The objective of this program is to provide a comprehensive understanding and practical application of basic file operations in Python, ensuring proper resource management and error handling.

📚 Theory
To execute this program, familiarity with core Python file-handling concepts is essential:
* File Modes:** Using `open()` with modes like `'w'` (write/overwrite), `'r'` (read), and `'a'` (append).
* Resource Management:** Ensuring files are properly handled (using context managers like `with open(...)` to prevent resource leaks).
* Error Handling:** Using `try-except` blocks to handle exceptions such as `IOError` for missing files or permission issues.
* File Utilities:** Using Python's built-in `shutil` module to seamlessly copy files from a source to a destination.


📝 Conclusion
Thus, we successfully implemented and understood File Handling operations (open, read, write, append, and copy) in Python.
